# cpp-web-billing
C++ coursework project focused on customer billing calculations, account validation, transaction processing, and input error handling.

# Web Billing System — C++

**Course:** COMP 1633 — Mount Royal University  
**Term:** Fall 2026  
**Language:** C++

## Overview

This project implements a web hosting billing system that processes customer account information and disk usage transactions to calculate monthly bills.

## Key Concepts

- **Input validation:** Checking account numbers and transaction records.
- **Billing calculations:** Calculating base charges, over-limit surcharges, penalties, and GST.
- **Transaction processing:** Processing multiple customer accounts and disk usage transactions.
- **Error handling:** Identifying invalid records, transaction codes, and amounts.
- **Functions and pass-by-reference:** Organizing program logic into functions and updating values through reference parameters.
- **File input:** Reading structured input using input redirection.

## Project Structure

- `part1/` — Processes and calculates a bill for a single customer.
- `part2/` — Extends the program to process multiple customers and individual disk usage transactions.

## Learning Outcomes

This project provided practice in C++ programming, algorithm development, incremental development, input validation, and structured problem-solving.
